# TeleCloudX

**Run the app from the my-next-app folder:**

```bash
cd my-next-app && npm run dev
```

---

## Project Structure

- `/app` — Old/unused landing page (do not run from here)
- `/my-next-app` — The actual running app (login, dashboard, billing, VMs, payments)

## Quick Start

```bash
cd my-next-app
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Root Scripts

You can also run these from the root `/TelecloudX` folder:

```bash
npm run dev    # cd my-next-app && npm run dev
npm run build  # cd my-next-app && npm run build
npm start      # cd my-next-app && npm start
```
